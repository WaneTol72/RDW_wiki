# Список команд и макросы

===============================================================

-  ***Ctrl+1***  - Изменить язык на англ

-  **num-lock {4, 2, 6, 8} + {7, 9, 1, 3}, + {5}** - Управление мышкой/курсором с помощью клавиатуры (когда *numlock* выключен, не горит индикатор на клавиатуры)
  **Ctrl + цифра на num-паде** - ускоренное передвижение мышкой/курсора

-  **Буфер обмена:**
1 - Первая команда для прошивки ПЗ
2 - Вторая команда для прошивки ПЗ (через terminal.exe)

====================== **Win+r command:** == ===========================

**06** - Прошивка Стаса
**16** - Прошивка Лехи
**33** - Прошивка создателя
**84** - Прошивка Евгения
**report** - Прошивка main

**uuid** - Прошивка UUID (автоматически, каждый раз разное значение)

**j** | **l** | **r** | **s** | **defaultname** (выбрать одно)- Меняет имя пользователя на серийный номер тестировщика (применяется  после перезагрузки)

**rv** | **sv** | **jv** | **lv** - Находит все порты и маки у коммутатора и сохраняет в файле на сервере
**rip** | **sip** | **jip** | **lip** - Меняет ip у каждого компа на 100 + номер порта у коммутатора

**dhcp** - Сбрасывает ip на автоматический

**off** - Выключить комп через *sysprep*
**res** - Перезагрузить комп через *sysprep*
**drop_audit** - Выйти из режима аудит и выключить компьютер через *sysprep*
**pxe** - Перезагрузить комп через *sysprep* и войти в *PXE IPv4*

**pz** - Открыть новую прогу ПЗ v3.1.1.2 (БЕЗ АВТОВВОДА)
**pz_old3** - Открыть прогу ПЗ v2.2.3.2 (БЕЗ АВТОВВОДА)
**pz_old2** - Открыть прогу ПЗ v1.1.1.2 (БЕЗ АВТОВВОДА)
**pz_old** - Открыть прогу ПЗ murus (С АВТОВВОДОМ)

**term** - Запуск terminal.exe для прошивки ПЗ
**typec** - Запуск прошивки type-c на *intel mother board*

**resol** - Батник смены разрешения на FHD (16:9)

**a520field** - Прошивает одно поле в мамке RDW A520. Поле - RDW A520. Перед использованием нужно в батникe bin4 (батник Жени) поменять тип прошивки на *'AMD'*


**ip** - Поменять ip на рандомный (Ремонтникам. Можно и Алексею, но в ***WDS*** все равно не зайдешь)
**ip+(r, j, s, a)** - Поменять ip на рандомный (но под разные стенды)


**eng\утп** - Меняем язык на *англ*, выключаем *caps lock*, выключаем *num lock*

**man** - Все команды

==================== **Прошивка BIOS** ================================

bios (локальная)			                                   bios__(name_of_version)
server_bios (сервер)		                           server_bios__(name_of_version)



=================== **Неактуальные батники** ============================


**scr(r/j/s/l)** - (тестовая функция) (scr + одна из букв: scrr) Делает скриншот на компе и отсылает в указанную папку
**stas/roman/jenya/lexa** - Открыть папку со скринами (нужно подключение к серверу по локальной сети)
**autostart** - Открыть папку автостарта


***Плата защиты:***
**pz_old** - Батник запуска платы защиты с автоматическим вводом admin (в разрешении FHD, 16:9)
**center** - Сбросить положение мышки к центру (почти центр)






**bug, bugb** - Взлом пентагона
