# Установка Linux

---

:::warning
*Возможны проблемы со входом в Linux  при включённом Secure boot.*
:::

>Включение протокола *Boot from onboard LAN (UEFI: PXE IPv4)/Network stack/UEFI PXE Support* для установки Linux **не требуется**.

---

Установку **Linux** производим через *флешку с Clonezilla.*

- Вставить флешку в выключенное изделие. Включить изделие/Перезагрузить.
- Вызвать *Boot menu* (клавиша вызова в соответствии с моделью MB)
- Выбрать в списке флешку (*UEFI: модель флешки)
- Дожидаемся загрузки окна навигации

Выбираем пункт  **restoredisk**

![Linux_starting.jpg](/SCR/LinuxScr/Linux_starting.jpg)

Далее выбираем интересующий нас образ в соответствии с ТЗ *(чаще всего, в имени указывается номер заказа, имя, количество штук в заказе/партии/этапе - год, дата, время создания образа, наименование накопителя, объем)*

![Linux_install.jpg](/SCR/LinuxScr/Linux_install.jpg)

Далее этап выбора накопителя. Если в заказе более 1 накопителя, нужно выбрать по очереди (поставить галочки пробелом/установка приоритета)

![Linux_M2_SSD_HDD.jpg](/SCR/LinuxScr/Linux_M2_SSD_HDD.jpg)

- В следующем окне, оставляем как есть **(-k0 Use the partition table from the image)**

![Linux_1.jpg](/SCR/LinuxScr/Linux_1.jpg)

- Следующий шаг остается неизменным

![Linux_2.jpg](/SCR/LinuxScr/Linux_2.jpg)

- Далее процесс установки/заливки **Linux**
- После установки, в появившемся окне выбираем один из вариантов  **(Выключение/Poweroff, Перезагрузка/Reboot)**

![Linux_end.jpg](/SCR/LinuxScr/Linux_end.jpg)

---

:::tip
Если после выбора одного из вариантов *"Выключение/перезагрузка"* изделие осталось включённым, введите команду ***Poweroff*** для выключения, либо ***Reboot*** для перезагрузки, регистр не важен.
:::

# Проверка изделия

---

>*Проверка одного экземпляра/изделия в рамках стенда!*

**Проверка изделия:**
- *Выходы* - (USB, Type-C, и т.п.) Front panel & I/O Shield (порты расположенные на MB)
- *Видеокарта* (при наличии) - выходы, разрешение.
- *Wi-Fi/BT* - качество сигнала, подключение (internet).
- *j 3.5* - звук и микрофон

**Моноблок**
- *Webcam* - проверяется через сайт (internet)
- *Частота обновления* изображения матрицы (60/75/100/120/144 МГц.)
