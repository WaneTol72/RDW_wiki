# Алгоритм проверки видеокарты


1.  **SDI** - Установить драйвер для устройства.
	- Если после установки драйвера устройство не работает, либо при установки драйвера произошла ошибка
		- скачать драйвер с официального сайта по модели устройства  [NVidia](https://www.nvidia.com/en-us/drivers/) ,  [AMD Radeon](https://www.amd.com/en/support/download/drivers.html) , **Intel®**.
		
 2.  ***FurMark***  - запустить программу с определенными надстройками (См. ТЗ/Planka).
	- Время тестирования:
		~15 min на 10% от общей партии заказа.
		~5 min на оставшейся партии
	- Проверить t° и FPS:
		- Температура не должна быть выше 85°
		- Температура и FPS должен быть одинаковым на всей партии (с допустимым отклонением 5-10%)
	- (Опционально) Запустить GPU Z для проверки характеристик видеокарты
	
3. Проверить все выходы: HDMI/DP/mDP/Type-C/WGA/DVI внешним монитором.


:::note
На слабых видеокартах FurMark не запускаем.
По типу **NVidia GeForce 710**
:::
