Материнские платы

В начало​

Материнские платы и актуальные прошивки

B450​

  • Актуальная версия прошивки: DB45MV10.16 - L0.16.
  • Метод прошивки: служба WDS команда 16.

A520​

  • Актуальная версия прошивки: RDW BIOS V2.7 - 2026/02/26.
  • Метод прошивки: служба WDS команда AR27.

B760D4​

  • Актуальная версия прошивки: E1.5D-E1.6 PL 50;65;200 - 2025/10/29.
  • Метод прошивки: UEFI SHELL: ONLY FLASH.

B760D5​

  • Актуальная версия прошивки: PL 50;65;200 - 2025/10/20.
  • Метод прошивки: UEFI SHELL: ONLY FLASH.

H610M​

  • Актуальная версия прошивки: PL 50;65;75 - 2025/09/09.
  • Метод прошивки: UEFI SHELL: ONLY FLASH.

H610-ITX (D5)​

  • Актуальная версия прошивки: 1610B1013 0.06 - 02/05/2026.
  • Метод прошивки: служба WDS команда h610i_v1.
  • Метод прошивки: служба WDS команда h610i_v2 (PL) прошить H610I с PL (50/55/65) (v1610B1013V0.08_RDW) v6_0

B850 (AM5)​

  • Актуальная версия прошивки: V8.0 r1 - 2025/11/28.
  • Метод прошивки: служба WDS команда B850v2.
  • Доработки: серийный номер шьем перед снятием отчета через BIOS.

B760I (MiniPC)​

  • Актуальная версия прошивки: v91 PL 30;35;45;50C
  • Метод прошивки: служба WDS команда M250

B560I (Old MiniPC rev1)​

  • Актуальная версия прошивки: v91
  • Метод прошивки: служба WDS команда B3
  • Доработки: Turbo mode -> Disable
