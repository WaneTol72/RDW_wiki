Скрипты и команды

В начало​

Список команд и макросы

На тестовой Windows​

Ctrl+1 - Изменить язык на eng.

  • num-lock: - Управление курсором с помощью клавиатуры (когда numlock выключен, не горит индикатор на клавиатуры).

    • 4, 2, 6, 8 (направление ←, ↓, →, ↑).
    • 7, 9, 1, 3 (направление по диагоналям).
    • 5 (имитация ЛКМ).

  • Ctrl + цифра на num-паде - ускоренное перемещение курсора.

  • center - Сбросить положение мышки к центру (почти центр).

Win+R command​

  • 06 - Прошивка Стаса.
  • 16 - Прошивка Лехи.
  • 33 - Прошивка инкогнито.
  • 84 - Прошивка Евгения.
  • report - Прошивка main.

uuid - Прошивка UUID (автоматически, каждый раз разное значение).

j | l | r | s | defaultname (выбрать одно)- Меняет имя пользователя на серийный номер тестировщика (применяется после перезагрузки).

iP​

Данные команды индивидуальны, по номеру стенда:

  • 1v | 2v | 3v | 4v | 5v | 6v | - Находит все порты и маки у коммутатора и сохраняет в файле на сервере.
  • 1ip | 2ip | 3ip | 4ip | 5ip | 6ip | - Меняет ip у каждого компа на 100 + номер порта у коммутатора.

dhcp - Сбрасывает ip на автоматический.

Работа с PC​

  • off - Выключить комп через sysprep.
  • res - Перезагрузить комп через sysprep.
  • drop_audit - Выйти из режима аудит и выключить компьютер через sysprep.
  • pxe - Перезагрузить комп через sysprep и войти в PXE IPv4 (работает ни на всех материнских платах).

ПЗПК​

  • pz - Открыть новую прогу ПЗ v3.1.1.2 (БЕЗ АВТОВВОДА).
  • pz_old3 - Открыть прогу ПЗ v2.2.3.2 (БЕЗ АВТОВВОДА).
  • pz_old2 - Открыть прогу ПЗ v1.1.1.2 (БЕЗ АВТОВВОДА).
  • pz_old - Открыть прогу ПЗ murus (С АВТОВВОДОМ).
  • term - Запуск terminal.exe для прошивки ПЗ.
  • Буфер обмена (Win + V):
    • Первая команда для прошивки ПЗ.
    • Вторая команда для прошивки ПЗ (через terminal.exe). pz_old - Батник запуска платы защиты с автоматическим вводом admin (в разрешении FHD, 16:9).

Общие​

typec - Запуск прошивки type-c на intel mother board.

resol - Батник смены разрешения на FHD (16:9).

a520field - Прошивает одно поле на материнской плате RDW A520. Поле - RDW A520. Перед использованием нужно в батникe bin4 (батник Жени) поменять тип прошивки на 'AMD'.

eng\утп - Меняем язык на eng, выключаем caps lock, выключаем num lock.

man - Все команды.

Прошивка BIOS​

server_bios (сервер) - server_bios__(name_of_version).

server_bios__AR27 (пример)

Неактуальные батники​

scr(r/j/s/l) - (тестовая функция) (scr + одна из букв: scrr) делает скриншот на компе и отсылает в указанную папку.

stas/roman/jenya/lexa - Открыть папку со скринами (нужно подключение к серверу по локальной сети).

autostart - Открыть папку автостарта.

bug, bugb - Взлом пентагона.
